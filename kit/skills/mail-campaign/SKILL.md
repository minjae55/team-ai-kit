# 안내 메일 발송 준비와 기록

> 요약: 이미 보낸 사람·수신 거부를 빼고 발송 목록과 개인별 초안을 만든다

## 절대 규칙
- **메일을 보내지 않는다.** 보낼 목록과 초안까지만 만든다. 실제 발송은 사람이 정한 도구(Gmail, Apps Script 등)로 사람이 승인한 뒤 한다.
- **같은 사람에게 두 번 보내지 않는다.** 발송 기록과 대조하는 판단은 `scripts/build_sendlist.py`가 한다.
- **발송 기록은 실제로 보낸 뒤에만 남긴다.** `scripts/log_sent.py`는 사람이 "보냈다"고 확인했을 때만 `--confirm`을 붙여 실행한다.
- 명단은 개인정보다. 외부 서비스에 올리거나 다른 곳에 복사하지 않는다.

## 1. 준비물 확인
업무용 `AGENTS.md`에서 명단 파일, 템플릿 위치, 발송 기록 파일, 수신 거부 목록, 캠페인 이름 규칙, 발송 도구를 찾는다. 빠진 것은 사람에게 묻는다.
- 명단은 먼저 `contact-db-check` 스킬로 점검하는 것을 권한다 (중복·형식 오류).
- 템플릿 형식은 `references/template-guide.md`를 따른다.

## 2. 발송 목록과 초안 만들기
스크립트는 이 SKILL.md가 있는 폴더의 `scripts/` 안에 있다. 전체 경로로 실행한다.
- 명령은 `&&`·`;`로 묶지 말고 **하나씩** 실행한다. 묶으면 권한 확인에서 한꺼번에 거부될 수 있다.
```bash
python3 /…/scripts/build_sendlist.py --contacts <명단.csv> --template <템플릿.md> --campaign <캠페인> \
  --sent-log <발송기록.csv> [--optout <수신거부.txt>] --out outbox
```
- 결과: `outbox/<캠페인>/list.csv`(보낼 대상), `skipped.csv`(제외와 이유), `drafts/`(개인별 초안)

## 3. 사람에게 확인받을 것
- 보낼 인원, 제외 인원과 이유 표 (스크립트 출력 그대로)
- 초안 1~2개 미리 보기 (이름·회사가 맞게 들어갔는지)
- "템플릿 값 없음"으로 빠진 사람: 값을 채울지, 기본값(`{{칸|기본값}}`)을 둘지

## 4. 구글 시트 + Gmail로 보낼 때 (Apps Script)
- `references/send_and_log.gs`를 사람에게 안내한다: `for_sheet.csv`를 시트로 가져오고, 스크립트를 붙여 넣고, "키트 발송" 메뉴에서 **미리보기 1통 → 발송(확인 창)** 순서로 한다.
- 스크립트는 한 번에 50명까지, 발송기록·발송상태로 중복을 막고, 보낸 사람을 "발송기록" 시트에 남긴다.
- 끝나면 "발송기록" 시트를 CSV로 내려받아 발송 기록 파일(예: `data/sent_log.csv`)을 바꾸게 안내한다. 이때는 5번의 `log_sent.py`가 필요 없다.
- 이 스크립트를 사람 대신 실행하거나 계정 권한을 허용하지 않는다.

## 5. 보낸 뒤 기록 (시트를 쓰지 않을 때)
사람이 실제로 보냈다고 알려 주면:
```bash
python3 /…/scripts/log_sent.py outbox/<캠페인>/list.csv --campaign <캠페인> --sent-log <발송기록.csv> --confirm [--only 1,2,5]
```
일부만 보냈으면 `--only`로 실제 보낸 번호만 남긴다. 반송·수신 거부 회신이 오면 수신 거부 목록에 추가한다.
