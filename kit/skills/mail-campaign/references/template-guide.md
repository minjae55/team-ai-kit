# 메일 템플릿 작성법

```
제목: [AI 캠퍼스] {{회사명}} 채용 담당자님께 훈련생 추천 안내

안녕하세요, {{담당자|채용 담당자}}님.
{{회사명}}의 {{분야}} 채용과 관련해 ... 안내드립니다.

(수신을 원하지 않으시면 회신으로 알려 주세요.)
```
- 첫 줄은 반드시 `제목: ...`, 그다음 빈 줄, 본문
- `{{칸이름}}`: 명단의 칸 값으로 바뀐다. 값이 없으면 그 사람은 제외된다 ("템플릿 값 없음")
- `{{칸이름|기본값}}`: 값이 없으면 기본값을 쓴다 (예: 담당자 이름을 모를 때)
- 수신 거부 방법을 본문에 넣는다. 광고성 정보에 해당하는지, 사전 동의가 필요한지는 업무 기준(회사 안내)을 따른다
