# 기본 커밋·PR 형식 (프로젝트 관례가 없을 때)

## 커밋
```
perf: 협의 목록 캐시 TTL에 jitter를 더해 동시 만료 방지

- TTL 60초 고정 → 60초 + 0~15초 무작위로 바꿔 여러 키가 한꺼번에 만료되지 않게 함
- 만료 직후 DB 동시 조회로 커넥션 풀이 포화되던 문제 (pending 최대 88 → 0, 같은 조건 k6)
- jitter 범위 단위 테스트 추가
```
- 한 커밋에는 한 가지 목적. 이름 변경·포맷 정리처럼 성격이 다른 변경은 따로
- 본문의 숫자는 측정 기록이 있을 때만

## PR 설명
```markdown
## 배경
(어떤 문제가 있었는지, 증상과 숫자)

## 변경
- (무엇을 어떻게 바꿨는지, 주요 파일)

## 검증
- (실제로 돌린 테스트, 부하 테스트 전후 숫자와 조건)

## 영향·위험
- (다른 기능에 미치는 영향, 되돌리는 방법)

## 리뷰 포인트
- (리뷰어가 특히 봐 줬으면 하는 부분)
```
