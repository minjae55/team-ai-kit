# 리뷰 체크리스트 (Java/Spring 기준, 다른 언어도 같은 원리)

## 정확성
- 조건이 반대이거나 경계값(>, >=)이 명세와 다름
- null·빈 컬렉션·없는 ID 처리, Optional.get() 남용
- 예외를 잡고 아무것도 안 함(삼킴), 잘못된 예외 타입으로 바꿈
- 상태 전이 검증 누락 (취소된 주문을 결제)

## 보안
- 문자열 이어 붙여 만든 SQL·JPQL·셸 명령 (`"... where name = '" + name + "'"`) → 바인딩 파라미터
- 요청한 사용자가 그 리소스의 주인인지 확인하지 않음 (IDOR)
- 비밀번호·토큰·개인정보를 로그에 출력
- 입력 검증(@Valid) 누락, 파일 경로 조작

## 트랜잭션·동시성
- `@Transactional`이 프록시를 거치지 않아 안 걸림: 같은 클래스 안에서 this.method() 호출, private·final 메서드
- 읽고-검사하고-쓰기를 락 없이 (재고 차감, 중복 가입) → 비관·낙관 락, 원자적 UPDATE, 유니크 제약
- 트랜잭션 안에서 외부 API·메일 호출 (커넥션을 오래 잡음, 롤백돼도 이미 보냄)
- readOnly 트랜잭션에서 쓰기

## 성능
- 반복문 안에서 리포지토리 호출 (N+1) → 한 번에 조회 (IN, fetch join)
- 페이지 없이 전체 조회 (findAll) 후 메모리에서 거르기
- 인덱스를 못 타는 조건 (컬럼 가공, 앞에 % LIKE) → query-analysis 스킬로 확인
- 캐시 키·TTL 설계 (동시 만료, 무한 증가)

## 테스트
- 바뀐 분기와 경계값을 검증하는 테스트가 있는지
- 테스트가 구현을 그대로 베껴서 아무것도 검증하지 않는지
