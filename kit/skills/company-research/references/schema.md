# 기본 DB 양식 (업무 AGENTS.md에 양식이 있으면 그것을 따른다)

| 칸 | 내용 | 예 |
|---|---|---|
| 회사명 | 정식 이름. (주)·주식회사는 빼고 통일 | 한빛로보틱스 |
| 분야 | 업무 기준의 조사 분야 중 하나 | 로봇 |
| 채용분야 | 공고의 직무 | 로봇 제어 SW 개발 |
| 공고제목 | 공고 제목 그대로 | 2026 하반기 로봇 SW 경력·신입 채용 |
| 공고마감 | YYYY-MM-DD, 상시면 "상시", 지났으면 "마감" | 2026-12-20 |
| 담당부서 | 공개된 부서 | 인사팀 |
| 담당자 | 공개된 경우만 | 채용담당 |
| 이메일 | 공개된 업무용 메일만 | recruit@... |
| 전화 | 공개된 대표·부서 번호만 (개인 휴대폰 금지) | 031-000-0000 |
| 출처 | 정보를 확인한 URL | https://.../careers |
| 확인일 | 조사한 날 YYYY-MM-DD | 2026-12-01 |
| 메모 | 애매한 점 | 공고는 포털에만 있음 |

- 한 회사에 공고가 여러 개면 분야에 맞는 대표 공고 하나를 쓰고, 나머지는 메모에 적는다.
- CSV는 UTF-8, 첫 줄은 칸 이름.
