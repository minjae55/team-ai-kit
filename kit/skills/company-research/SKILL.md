# 채용 기업 조사

> 요약: 채용 기업을 공개 정보만으로 출처·확인일과 함께 정리한다

## 절대 규칙
- **출처 없는 정보는 넣지 않는다.** 행마다 출처 URL과 확인일을 남긴다. 기억이나 추측으로 연락처를 만들지 않는다.
- **공개된 업무용 연락처만** 모은다 (회사 채용 페이지·공고에 적힌 인사팀 메일, 대표·부서 전화). 개인 휴대폰, 개인 SNS, 블로그·커뮤니티에 올라온 개인 연락처는 넣지 않는다.
- **사이트 약관을 지킨다.** 채용 포털은 자동 수집(크롤링)을 금지하는 곳이 많다. 공식 API, 회사 채용 페이지, 공개 공고를 우선하고 대량 자동 수집은 사람에게 먼저 확인한다.
- 마감된 공고는 "마감"으로 표시하고 지금 채용 중인 것처럼 쓰지 않는다.

## 1. 기준 확인
업무용 `AGENTS.md`에서 다음을 읽는다. 이 스킬은 업무별 값을 갖고 있지 않다.
- 조사 분야(예: 과정별 직무), 대상 기업 조건(지역, 규모 등)
- DB 칸 구성과 저장 위치 (없으면 `references/schema.md`의 기본 양식)
- 기존 DB 파일 (이미 있는 회사는 새로 넣지 않고 갱신 후보로 표시)

## 2. 조사
- 분야마다 검색어를 정하고(직무명, 장비·기술 키워드) 회사 채용 페이지와 공식 공고를 찾는다.
- 회사마다 확인할 것: 정식 회사명, 해당 분야 채용 여부(공고 제목·마감일), 담당 부서, 공개 연락처, 출처 URL
- 분야에 맞지 않는 회사(예: 직무가 영업만 있음)는 넣지 않고 "제외" 목록에 이유와 함께 적는다.

## 3. 정리
- `references/schema.md` 양식(또는 업무 AGENTS.md의 양식)으로 CSV에 쓴다. 확인일은 오늘 날짜.
- 정리 후 `contact-db-check` 스킬로 중복·형식을 점검하는 것을 권한다.

## 4. 결과 보고
- 추가한 회사 수(분야별), 제외한 회사와 이유, 연락처를 못 찾은 회사, 마감 공고
- 사람이 확인해야 할 것 (애매한 분야 판단, 연락처 출처가 약한 경우)
