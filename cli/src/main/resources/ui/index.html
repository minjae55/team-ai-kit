AI 에이전트

이 PC의 AI 도구에 팀 스킬과 공통 원칙이 연결된 상태예요. 새 도구를 깔면 다음 업데이트 때 자동으로 연결돼요.

웹 AI · 자동 분석
🌐
웹 AI에서 쓰기
claude.ai · ChatGPT · Gemini에 올릴 묶음 만들기
▶
웹 AI는 자동으로 갱신할 수 없어서, 올릴 묶음을 만들고 바뀐 스킬을 알려 드려요. 웹에서는 내 PC 스크립트(DB 조회 등)를 실행할 수 없어요.
🔔
알림 자동 분석
Grafana 알림이 오면 원인을 자동으로 분석
▶
터미널에서 kit watch --project <프로젝트 폴더> --listen-all을 켜 두고, 화면에 나온 주소를 Grafana 연락처(webhook)에 넣으면 돼요. 읽기 전용으로 분석하고, 같은 알림은 30분에 한 번만 분석해요. 결과는 ~/.kit/alerts/에 남아요.

활동 기록

내가 개선한 것과 AI로 한 작업이에요. 누르면 자세히 보이고, 스킬을 쓴 결과는 평가해 주세요.
