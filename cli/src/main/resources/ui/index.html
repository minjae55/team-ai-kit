웹 AI에서 쓰기 (claude.ai · ChatGPT · Gemini)
웹 AI는 자동으로 갱신할 수 없어서, 올릴 묶음을 만들고 바뀐 스킬을 알려 드려요. 올리는 법은 각 폴더의 올리는법.txt에 있어요. 웹에서는 내 PC 스크립트(DB 조회 등)를 실행할 수 없어요.
초기화
키트가 설치한 것(팀 스킬 연결, 공통 원칙 구역, 자동 업데이트 훅)을 지워 설치 전으로 되돌려요. 직접 만든 개인 스킬과 직접 쓴 지침은 그대로 둬요. 지울 목록을 먼저 보여 드려요.
